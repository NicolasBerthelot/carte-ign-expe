Cartes IGN

Version d'expérimentation

Installez cette version sur votre téléphone, votre tablette ou votre ordinateur : elle s'ouvre comme une application, en plein écran, depuis l'écran d'accueil. Elle se met à jour automatiquement.

Elle s'installe à côté de l'application Cartes IGN officielle, sans la remplacer.

✓ Application installée : retrouvez « Cartes IGN β » sur votre écran d'accueil.

Sur iPhone ou iPad (Safari)

  1. Touchez le bouton Partager (le carré avec une flèche vers le haut).
  2. Choisissez Sur l'écran d'accueil.
  3. Touchez Ajouter.

L'installation n'est possible que depuis Safari.

Sur Android (Chrome)

  1. Ouvrez le menu ⋮ en haut à droite.
  2. Choisissez Installer l'application ou Ajouter à l'écran d'accueil.

Sur ordinateur

Dans Chrome ou Edge, cliquez sur l'icône d'installation à droite de la barre d'adresse. Pour l'installer sur un téléphone, scannez ce code :

nicolasberthelot.github.io/carte-ign-expe/installer.html
